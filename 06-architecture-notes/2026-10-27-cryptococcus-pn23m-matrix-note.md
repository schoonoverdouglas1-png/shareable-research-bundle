## Three lettering schemes, side by side
1. Meningococcal (from the essay, already tested Oct 27): letters only, A/B/C/W/Y, each a different capsular polysaccharide; changing the letter predicts a change in chemistry and vaccine approach.
2. Cryptococcus (from tonight's email, unverified): letters only, A–D, but each letter masks multiple molecular types:
   - A = VNI, VNII, VNB — Cryptococcus neoformans var. grubii
   - D = VNIV — Cryptococcus deneoformans (formerly var. neoformans)
   - AD = VNIII — hybrid (grubii x deneoformans), dual-capsular expression
   - B = VGI, VGII, VGIII — Cryptococcus gattii complex
   - C = VGIV — Cryptococcus gattii complex
   So here a single letter hides three molecular types (A, B) — the masking point of P1, in a fungal system.
3. Pneumococcal (from tonight's email, unverified): numbers first, letters trailing — e.g. serogroup 10, subtypes 10A vs 10B/10C/10F, differing (per the email) in sugar composition or O-acetylation, with asymmetric antibody cross-reactivity; 10A is named as a PCV20/PPSV23 target.
